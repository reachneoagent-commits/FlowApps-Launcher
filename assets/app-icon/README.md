# FlowApps app icon

The app icon is the FlowApps brand icon, `brand/Icon Exports/Icon-iOS-Default-1024x1024@1x.png`.
The PNGs, `flowapps-launcher.ico` and `flowapps-launcher.icns` in this folder are resized from it
(`sips` for the sizes, then `cargo xtask ico` and `cargo xtask icns`). Replace them from the brand
file; don't edit them by hand. The FlowApps name and logo are trademarks of Reach Neo.
