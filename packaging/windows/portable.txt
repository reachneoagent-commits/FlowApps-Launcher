FlowApps portable mode

While this file sits next to flowapps-launcher.exe, FlowApps keeps its settings, its
download cache and its record of installed apps in the FlowAppsLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move FlowApps with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\FlowApps) instead.
If FlowAppsLauncherData can't be written (for example on a read-only drive), FlowApps says
so and uses %APPDATA%\FlowApps instead.
